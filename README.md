# けいさんピラミッド

小学2年生向けの計算ピラミッド練習ツールです。下の2つの数をたすと、上の数になります。空いているマスに数を入れて解きます。

## つかいかた

`index.html` をブラウザで開くだけで動きます。インストールは不要です。

- **だんの数**：3だん / 4だん
- **むずかしさ**：てっぺんが 100まで / 300まで / 999まで
- **もんだい**：たしざん だけ / ひきざんも（下の段にも空きがあり、ひき算で解く）
- **ヒント**：いま解けるマスと、使う2つの数を光らせて式を表示
- **こたえあわせ**：正解は緑、まちがいは赤。全部できると ★ が1つ増える

★の数と設定は、そのブラウザの localStorage に保存されます。

## GitHub Pages で公開する

リポジトリの Settings → Pages で、Branch を `main` / `(root)` にして保存すると、
`https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります。
